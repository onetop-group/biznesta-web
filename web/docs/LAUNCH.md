## A-보충. 개인정보 보관기간 추천안 (사용자 확정 전 — 적용하지 않음)

세 가지 안을 비교한 결과 **OPTION B — 마지막 상담일(`created_at`) 기준 일정
기간 보관 후 삭제** 를 추천한다.

| | OPTION A 상담 종료 후 | **OPTION B created_at 기준** | OPTION C 장기 고객관리 별도 동의 |
|---|---|---|---|
| 운영 | 단순하나 종료 판정이 필요 | 기준이 하나뿐이라 분쟁 여지 적음 | 재제안·유지보수에 유리 |
| 최소수집 | 좋음 | 좋음 | 부담 큼 — 동의 분리 필수 |
| DB 영향 | 종료 시각 컬럼 추가 필요 | **추가 컬럼 없음** | 동의 항목·컬럼 추가, 폼 UI 변경 |
| 자동삭제 | 필요 | 필요 | 필요 + 철회 처리 |

**주의**: 구체적인 기간은 법으로 정해진 값이 아니라 사업자가 정해 고지하는
값이다. 기간을 임의로 정하지 않았고, `/privacy` 에도 넣지 않았다.
사용자가 기간을 확정한 뒤에야 방침 문구와 자동삭제를 함께 구현한다.
**현재 DB 에 자동삭제 기능은 없다.**
